> UI 拡張・マーケットプレイス・追加権限は今後の拡張対象です。現在の実装範囲は下記のインストール、検証、実行、設定 API です。

## 概要

Vyline は外部プラグインで挙動を拡張できます。

- 読み込み方式: **ES Modules**（動的ロード）→ 再ビルド不要でプラグイン追加
- 配布: 設定画面から ZIP 選択、または `backend/data/plugins/` への配置
- 権限: プラグインごとの許可（メッセージ送信・メディア取得・テーマ変更など）を明示的に付与

## 現在の API 面

| 領域         | 内容                                                   |
| ------------ | ------------------------------------------------------ |
| 実行         | `activate()` / `deactivate()` の隔離実行                |
| メッセージ   | `messages:read` 権限による受信購読                      |
| 設定         | `settings:read` / `settings:write` のアカウント別保存   |
| 配布         | ZIP Slip、容量、ファイル数、manifest、entry の検証      |

## Usage

ZIP は `manifest.json` と `index.ts` または `index.js` を含む必要があります。設定画面の「プラグイン」から ZIP を選択し、詳細を確認して有効化します。プラグインは backend と同じ Bun プロセスで動くため、信頼できるファイルだけを導入してください。
