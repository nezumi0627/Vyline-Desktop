01 / SETUP GUIDE

迷わず始めるための、
最短ルート。

使い方に合わせて入口を選んでください。デスクトップ版の導入からセルフホスト、更新まで、一次資料へ直接つながります。

01 Download beta Windows / Linux向けの最新リリースを取得 RELEASES +

Vylineを試す最初のステップです。GitHub Releasesから最新版を選び、利用するOSのパッケージをダウンロードしてください。

  • Windows: セットアップ実行ファイルを起動
  • Linux: x64アーカイブを展開して起動
  • Beta版のため、利用前に注意事項を確認
GitHubでリリースを見る ↗
02 First setup 必要環境、起動、ログインまでの初回ガイド ONBOARDING +

初回起動に必要な環境変数、バックエンドとフロントエンドの起動、ログインまでを順番に確認できます。

  • Bun 1.4以上と依存関係を準備
  • 開発サーバーまたは配布版を起動
  • QR / Emailログインと同意ゲートを完了
Markdown原文を読む ↗
03 Self-host DockerとCloudflare Accessで自分の環境へ DEPLOYMENT +

データとセッションを自分で管理したい人向けの導入方法です。Docker Composeを使い、必要に応じてCloudflare Accessを前段に置けます。

  • Docker Composeでバックエンドを起動
  • 静的フロントエンドの公開先を設定
  • 外部公開時は認証と秘密情報の扱いを確認
Markdown原文を読む ↗
04 Keep updated 安全に最新版へ更新するための手順 USER GUIDE +

更新前にデータと設定を確認し、リリースノートに目を通してから最新版へ移行します。

  • 重要なバックアップを先に作成
  • 変更点と既知の注意事項を確認
  • 更新後にログインと同期状態を確認
Markdown原文を読む ↗
05 Explore the API Swaggerで仕様を読み、実際のエンドポイントを確認 OPENAPI 3.1 +

API利用者はSwagger UIからPublic APIと内部BFFの仕様を切り替え、パラメータ、レスポンス、認証方式を確認できます。

  • Public API: 安定した外部利用向け
  • BFF API: フロントエンド内部向け
  • OpenAPI JSON / YAMLもGitHubから取得可能
Swagger UIを開く ↗
